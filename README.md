
# Vent Haven Museum — Web Design I Group Coding Exercise

In this coding exercise, you'll build a three-page website for the Vent Haven Museum, a museum dedicated to the history and art of ventriloquism in Fort Mitchell, Kentucky.

You'll use HTML and CSS to create the website's structure, add content, build navigation, and design the page layouts.

**This repository contains the STARTER files, not the completed website.** You'll be writing the HTML and CSS yourself!

## What You'll Learn

This exercise combines several skills we've covered in Web Design I:

- Writing standards-compliant, semantic HTML
- Creating a multi-page website
- Building a consistent header, navigation bar, and footer
- Linking external stylesheets
- Using Flexbox and CSS Grid for page layouts
- Adding and positioning images
- Styling text, backgrounds, borders, and other elements
- Publishing a completed website using GitHub Pages
- Working collaboratively to solve coding problems

## Getting Started

Start by opening the assignment in Canvas and following the link to this template repository.

1. Click **Use this template** at the top of this repository.
2. Select **Create a new repository**.
3. Choose your GitHub account as the owner and give your repository a name.
4. Make your new repository **Public** and click **Create repository**.
5. Open GitHub Desktop and clone your newly created repository to your computer.
6. Open the repository folder in Visual Studio Code.
7. Follow the printed instructions provided in class.

**Important:** Create your repository from the template before starting the coding exercise. Don't work directly in my original template repository.



## Starter Files

This repository contains the following resources:

- `page_content_info.html` — The written content you'll use to build the website. This is a reference file, not one of your finished website pages.
- `reset.css` — A provided CSS reset stylesheet.
- `images/` — Photographs and decorative graphics you can use in your website.

## Files You'll Create

You'll create the following files during the exercise:

| File | Purpose |
|---|---|
| `index.html` | Museum homepage |
| `berger.html` | William S. Berger biography |
| `dummy.html` | Featured ventriloquist dummies |
| `vent.css` | Your custom CSS stylesheet |

All three HTML pages should share a consistent header, navigation bar, footer, and visual design.

**Don't create all these files immediately!** Follow the printed handouts and complete the steps in the order they're presented.

## Finishing the Exercise

When your website is finished:

1. Use Live Preview in Visual Studio Code to test all three pages.
2. **Commit** and **push** your completed work to GitHub using GitHub Desktop.
3. Share the URL of your finished repository with your partner.
4. The second partner should **fork the finished repository** to create a personal copy in their own GitHub account.
5. Both partners should publish their own websites using **GitHub Pages**.
6. Both partners should add their published website URLs to the **About** sections of their repositories.
7. Each student must submit their own GitHub repository URL and live website URL through Canvas.


## A Note About the Museum Information

The text supplied for this exercise is historical classroom material. Some information about museum hours, admission prices, and visitor policies may no longer be accurate.

The purpose of this exercise is to practice web development, not to create an official museum website.
