# Vent Haven Museum — Web Design I Group Exercise

**This is a starter template, not a completed website.** The exercise is to build three HTML pages and style them with CSS.

## One computer, two partners

- **Part 1 (HTML):** Partner A is the **driver** (typing); Partner B is the **co-pilot** (reading instructions, checking code, helping troubleshoot).
- **Checkpoint:** Show your instructor the three HTML pages before starting the styling handout.
- **Part 2 (CSS):** **Switch roles.** Partner B drives and Partner A is the co-pilot.
- Work on **one computer and one repository**; you do not need Git collaboration features.

## Start the project

1. Partner A signs in to GitHub and selects **Use this template → Create a new repository**. Make the new repository **Public** so Partner B can fork it at the end.
2. Partner A opens their new repository in **GitHub Desktop**, using **File → Clone repository**, then opens its folder in **VS Code**.
3. Follow the printed **Part 1 — HTML** handout and then **Part 2 — CSS**. Preview using VS Code **Live Preview**.
4. When finished, save everything. In GitHub Desktop, **Commit to main** and then **Push origin**.

## Give both partners their own GitHub copy

1. Partner A sends Partner B the **URL of the finished repository** (not the starter template).
2. Partner B visits that URL while signed into GitHub and chooses **Fork → Create a new fork**.
3. Partner B now has their **own GitHub repository** with the group's completed site. Partner B can clone this fork in GitHub Desktop if they want a local copy.
4. Both partners confirm the project includes `index.html`, `berger.html`, `dummy.html`, the CSS file, and images.

## Starter files

- `page_content_info.html`: text to copy into your website pages; **not itself a site page**
- `reset.css`: provided CSS reset
- `images/`: supplied photographs and decorative artwork

## Files you create

- `index.html` — homepage
- `berger.html` — founder biography
- `dummy.html` — featured dummies
- `vent.css` — your own CSS rules

The supplied museum text is a **historical classroom example**; the visitor prices and policies may no longer be current.
